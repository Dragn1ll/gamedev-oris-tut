# Список задач

Этап 2. Консольный веб-сервер на .NET 10 с `HttpListener` и собственным HTML-шаблонизатором.

## Запуск

В корне репозитория выполните команды.

```sh
dotnet --version
dotnet build
dotnet run --no-build
```

Для сборки нужен .NET SDK 10. Сервер слушает `http://localhost:8080/`. Для остановки нажмите Ctrl+C.

## Проверка

В другом терминале выполните команды.

```sh
curl -i http://localhost:8080/
curl -i http://localhost:8080/tasks
curl -i http://localhost:8080/unknown
```

Первый запрос вернёт `200` и текст «Сервер работает». Второй вернёт `200` и HTML со списком задач. Третий вернёт `404` и HTML-страницу ошибки.

## Как обрабатывается GET /tasks

1. `GetContextAsync()` возвращает контекст запроса. Сервер берёт из него метод и путь.
2. Обработчик логирования пишет метод и путь, запускает таймер и вызывает `next`. Обработчик ошибок передаёт управление маршрутизатору своим вызовом `next`.
3. Маршрутизатор сопоставляет пару `GET` и `/tasks`, создаёт модель с задачами из памяти и читает шаблон `tasks.html` из папки приложения. Сборка копирует туда этот файл. Шаблонизатор получает текст шаблона и модель и возвращает HTML. Сервер отправляет его со статусом `200` и типом `text/html; charset=utf-8`.
4. Если маршрутизатор выбрасывает исключение, обработчик ошибок пишет подробности в журнал. До начала отправки он возвращает HTML со статусом `500`. Если отправка уже началась, он прерывает ответ.
5. Логирование записывает статус и время в миллисекундах. Сервер закрывает ответ, а цикл принимает следующий запрос.

## Синтаксис шаблона

```html
<h1>@Model.Title</h1>
@if (Model.IsEmpty) { <p>Задач пока нет</p> }
<ul>
    @foreach (var task in Model.Tasks) {
        @if (task.IsCompleted) { <li><s>@task.Title</s></li> }
        @if (task.IsPending) { <li>@task.Title</li> }
    }
</ul>
```

Выражения обращаются к публичным свойствам модели или текущего элемента цикла. Движок экранирует подставляемый текст через `WebUtility.HtmlEncode`. Он разбирает тело каждой директивы как отдельный блок. При выводе `foreach` задаёт переменную `task` для текущего элемента, и вложенный `if` читает её булево свойство. Ошибка шаблона содержит позицию в файле и попадает в журнал сервера.
